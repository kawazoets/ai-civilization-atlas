# 150回以上、履歴書を書き直してきた

シンガポールに来てから約10年になる。この10年間で、私は履歴書を150回以上書き直してきた。専用フォルダーにあるPDFを数えてみるとそうだった。

仕事が変わるたびに更新し、応募する会社によって内容を変え、書類選考や面接が通らなければまた修正する。日本語のみならず英語の表現も変え、Professional Summaryを書き直し、経験の見せ方を変えてみる。

そうしたことを繰り返したら150回以上になってしまった。山登りではないが、58歳になった今も、私はまだ履歴書を書き直している。

30年前から早期リタイヤを目指していたが、なかなか人生とは計画どおりにはいかないものだ。

ここ2年はAIも使うようになった。以前なら一つの表現を直すだけでも時間がかかったが、今では短時間で何通りもの候補を比較できる。だから逆に、以前より細かいニュアンスまで気にして、履歴書を書き直す回数は増えたかもしれない。

## 一つの専門分野を歩いてきたわけではないために

いままで経験した仕事を並べると、自分でもかなりばらばらに見える。

営業。
企画。
管理。
システム。
人事。
会計。
財務。

そして現在は、半導体製造の現場にいる。

今の仕事では、製造設備に関わる日本人エンジニアと多国籍スタッフの間に入り、通訳や調整をしている。

PLC、制御盤、AMR、コンベアといった以前の私にはほとんど縁のなかった言葉が、今では日常の仕事の中にある。

私はエンジニアになったわけではない。志望したわけでもない。それでも、エンジニア同士が何について話しているのか、その問題が設備全体のどこに位置しているのかを理解する必要がある。

そのために分からないことを一つずつ調べてきた。

## AIが現れて、学び方が変わった

生成AIが現れたことは、私にとって大きな変化を与えた。良い意味でも悪い意味でもなく事象の話だ。

知らない技術用語が出てきたときに、以前なら検索をして、複数のWebサイトを読み、それでも理解できなければ諦めることもあった。

今はAIに何度でも質問できる。

「PLCとは何か」から始めて、「この制御盤の中でPLCはどこにあるのか」「24VDCはなぜ必要なのか」「I/Oは何をしているのか」と、自分が理解できるところまで質問を細かくしていける。

英語についても同じだった。

英語が突然上手になったわけではない。しかし、分からない文章を確認し、自分の言い回しを修正し、相手に伝わる形に整えるまでの距離は大幅に短くなった。

そして現場で必要になれば、Quick Helpのような簡単な資料もGithubで自分で作るようになった。

AIによって専門家になったわけではない。むしろ、**専門家ではない自分が、知らない領域に入っていくための距離が短くなった**。

## それでもキャリアは完成していない

ここまで書くと、「58歳でも新しい仕事に挑戦できた」という成功談のように見えるかもしれない。しかし、そうではない。

私は今も定職についているわけではない。期限付きの短期労働者である。そして、次に何をするのかも決まっていない。

だからまた履歴書を書き直している。

偉そうに「50代からはこう働けばいい」と誰かに教えることもできないのは、私自身がまだ答えを持っていないからだ。

ただ、この10年間で一つだけ確かなことがある。仕事が変わるたびに、自分に必要なものを少しずつ覚えてきた。それが営業だったこともある。人事だったこともある。会計や財務だったこともある。

そして今は、PLCやAMRについて勉強している。GPUについてもAIについてもそうだ。

一本の専門性をきれいに積み上げてきたキャリアではないが、必要になるたびに、自分の役割を書き換えてきた。

履歴書を150回以上書き直してきたことは、その記録なのかもしれない。

面接では、キャリアに一貫性や軸がないと評されることもある。そう見えるのも分かる。でも、これが自分の歩いてきた人生だ。

## AI時代に仕事とどう向き合うのか

最近、AIによってどの仕事がなくなるのか、どの仕事が残るのかという議論をよく目にする。

私自身もAIについて多くのことを書き調べてきたが、自分自身の問題として考えているのは、AI時代にどうやって働き続けるかというよりは、**AI時代に自分は何のために働くのか、仕事とどう向き合うのか、ということを考えるようになった。**

AIができることはこれからさらに増えていくだろう。私自身も、この2年間でAIに助けられることがずいぶん増えた。英語を書くことも、知らない技術を学ぶことも、情報を調べることも、勉強をすることも以前よりずっと簡単になった。

だからこそ、人間が何をできるかだけではなく、**自分は何をしたいのか、なぜそれをするのか**を考える時間が増えたように思う。

今いる半導体製造の現場でも、最初からそこに何か大きな意味を求めていたわけではない。分からないことを調べ、人の話を聞き、自分にできることを探してきた。そうしているうちに、仕事というものを以前とは少し違って見るようになった。

仕事とは、完成した専門性を提供することだけではないのかもしれない。知らない場所に入り、そこで何が必要なのかを考え、自分にできることを少しずつ見つけていく。

少なくとも今の私にとって、仕事と向き合うというのは、そういうことに近くなってきている。

58歳になった今も、私はまだその答えを探している。そして、この文章を書いている今も、また履歴書を書き直している。

150回以上書いた。もう十分書いた。

**できれば、もうこれ以上は履歴書を書き直したくない。**
